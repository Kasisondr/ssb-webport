Player ports

Port 1 is the keyboard until a gamepad claims it first.

Automatic keeps the native rules: gamepads take ports 1..n in the order the browser sees them, the keyboard always holds one so keyboard + mouse needs no setup, and a pad used before the keyboard takes port 1 because 1P mode is fixed to it. Closing a port means nothing can join it. The buttons a controller drives are set above, and they follow the controller rather than the port it lands on.
